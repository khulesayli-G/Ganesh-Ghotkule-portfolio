# Ganesh Shankar Ghotkule — DevOps Portfolio

A responsive, minimal professional portfolio website built with HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a web browser.

## Publish
Upload the contents of this folder to a static hosting provider such as GitHub Pages, Netlify or your web host.

## Update before publishing
- Confirm the employment dates and job titles.
- Add any missing responsibilities or project details only if accurate.
- Add a resume PDF at `assets/Ganesh_Ghotkule_ATS_Resume.pdf`. The ATS resume is included if it was available when this site was generated.
- If the resume PDF is not included, add it to the `assets` folder using that exact filename, or update the two resume links in `index.html`.

## Content note
The site is based on the supplied resume. It does not add unverified project metrics, certifications, qualifications or achievements.
